# Incognito Browser -- Programmatic SEO System

A programmatic SEO engine that auto-generates hundreds of privacy-focused resource pages for **incognitobrowser.com**. Built on Next.js, deployed on Vercel, with content generated by Claude AI. Every page is statically rendered at build time for maximum SEO performance.

## Why This Exists

Incognito Browser needs organic search traffic across a wide range of privacy topics. Manually writing 500+ pages is not viable. This system solves that by:

1. Defining a **taxonomy** of 44 privacy niches with audience and keyword data
2. Defining **schemas** that enforce consistent page structure and depth
3. Running an **AI generator** that produces targeted content for every niche x content type combination
4. Building a **static Next.js site** that turns that content into fast, SEO-optimized pages

The result: 514 static pages covering the entire privacy landscape, each tailored to a specific audience with specific pain points, all linking to Incognito Browser as the recommended solution.

## How It Works

### Three layers

**1. Taxonomy** (`data/taxonomy.json`)

44 privacy niches organized into 5 tiers. Each niche carries:

- Target audience (who we're writing for)
- Pain points (what frustrates them)
- Monetization angle (how it drives revenue)
- Content that works (what formats perform)
- Subtopics (long-tail keywords to target)

Example:

```
Incognito Mode
  Audience: Everyday browser users, people sharing devices, online shoppers
  Pain points: Misconceptions about what incognito hides, false sense of total privacy
  Subtopics: chrome incognito mode, firefox private browsing, incognito vs VPN
```

**2. Schemas** (`scripts/schemas/`)

7 content types, each with a strict JSON schema that enforces density rules -- item counts, required fields, keyword arrays. This ensures every generated page has consistent depth.

**3. Generator** (`scripts/generate-content.ts`)

A script that loops through niches x content types, calls Claude with the niche context + schema, and writes structured JSON files. The site reads these at build time to produce static HTML.

## Recent Changes

### Interactive Privacy Tools (11 engines across 44 niches)
- **Password Strength Analyzer** -- real entropy calculation, crack time estimation, pattern detection
- **Password Generator** -- CSPRNG-based passwords and passphrases with configurable options
- **Browser Privacy Audit** -- 14 checks across tracking, fingerprinting, and leak categories
- **Text Encryption/Decryption** -- AES-256-GCM via Web Crypto API with PBKDF2 key derivation
- **URL Safety Analyzer** -- detects suspicious TLDs, shorteners, homograph attacks, credential harvesting
- **Hash Generator** -- SHA-1/256/384/512 with text and file input modes
- **Privacy Quiz** -- 12 questions across 5 categories with personalized recommendations
- **Permission Checker** -- queries 11 browser permissions with risk assessments
- **Cookie & Tracker Scanner** -- scans URLs server-side for cookies, tracking scripts, and security headers
- **User Agent Analyzer** -- parses browser/OS/engine with privacy concern ratings
- **Metadata Viewer** -- client-side JPEG EXIF parser detecting GPS, camera info, timestamps

Each engine is mapped to relevant niches via a registry (`components/tools/registry.tsx`), so all 44 niche tool pages render a real, functional tool.

### Hub-and-Spoke SEO Architecture
- **Niche hub pages** at `/topics/[niche]/` -- 44 pages aggregating all content types per privacy topic
- **Cross-content-type linking** -- every detail page shows related resources from the same niche (guides link to checklists, tools, comparisons, etc.)
- **Clickable homepage topic grid** -- all niche cards and popular topic pills link to hub pages
- **Sitemap updated** with hub pages at priority 0.7

### URL Scanner API
- Server-side POST endpoint at `/api/scan-url` fetches URLs and analyzes Set-Cookie headers, tracking scripts (33 patterns), third-party domains, and security headers
- Returns privacy grade (A-F) with detailed breakdown

### Branding
- Real Incognito Browser icon (hat + sunglasses SVG) used as favicon and throughout header/footer navigation

## SEO Mechanics

- **Per-article keywords** (3-6) generated from niche context and subtopics
- **Internal cross-linking** between content types, niches, and glossary terms
- **Structured data** -- BreadcrumbList, HowTo, FAQPage schema markup on every page
- **XML sitemap** auto-generated with priority weighting by content type
- **Static HTML** -- zero client-side rendering overhead, fast Core Web Vitals

## Monetization Paths

- **Product signups** -- Incognito Browser download CTAs embedded throughout
- **Affiliate** -- VPNs, password managers, data removal services (high-commission recurring products)
- **Display ads** -- high-volume informational traffic across 500+ pages

## Scaling

Adding a new niche: add one entry to `taxonomy.json`, run the generator. Every content type is produced automatically.

Adding a new content type: add a schema, add a config entry in the generator, add a Next.js route. It then generates across all 44 niches.

## Generating Content

Requires `ANTHROPIC_API_KEY` in a `.env` file.

```bash
# Generate everything
npx tsx scripts/generate-content.ts --type all

# Generate one content type
npx tsx scripts/generate-content.ts --type checklists

# Generate for one niche
npx tsx scripts/generate-content.ts --type guides --niche incognito-mode

# Preview what would be generated (no API calls)
npx tsx scripts/generate-content.ts --type all --dry-run
```

The generator skips existing files, so it's safe to re-run. To regenerate, delete the relevant `data/` subdirectory first.
